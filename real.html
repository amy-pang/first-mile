        How this drive is scored

        Same system as the practice rotary: 100 points across six categories. Steady habits lose points every second they slip; one-off rules lose a set amount. Critical errors fail the run whatever the score: any collision, running a red light, driving through an occupied crosswalk, an unsafe lane change, or turning right across a cyclist.

          Rules summarized for practice. Check the official Massachusetts Driver's Manual from the RMV before your road test.
